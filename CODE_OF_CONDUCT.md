# Code of Conduct

NetPulse contributors are expected to be respectful, constructive, and welcoming. Harassment, personal attacks, discrimination, doxxing, and deliberately disruptive behavior are not acceptable.

Communicate in good faith, focus criticism on ideas and code, respect differing levels of experience, and help keep technical discussions safe and accessible.

Report conduct concerns privately to the repository owner through GitHub. Do not publish personal information or sensitive evidence in a public issue.
