---
name: ui-review
description: Review NetPulse UI against design tokens, WCAG 2.2 AA, keyboard behavior, responsive states, and the empty/loading/error state requirements.
---

1. Capture desktop and mobile screenshots in light/dark themes once both themes exist.
2. Inspect normal, loading, empty, error, keyboard focus, and reduced-motion behavior.
3. Run axe and keyboard-only checks where tooling is available.
4. Report findings by severity and cite the specification/criterion.
5. If a browser is unavailable, mark visual review as not tested; never claim that screenshots were reviewed when they were not.
